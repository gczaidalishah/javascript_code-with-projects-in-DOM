## Contents

### Root JavaScript files

- `api.js` - API-related JavaScript practice.
- `app.js`, `app2.js` - application/example scripts.
- `function.js` - function practice.
- `highfunction.js` - higher-order function practice.
- `methods.js` - JavaScript methods practice.
- `movie.js` - movie-related JavaScript example.
- `object.js` - object practice.
- `others.js` - additional JavaScript examples.
- `scope.js` - scope practice.

### `Mini_projects/`

Small HTML, CSS, and JavaScript exercises that can be opened in a browser.

- `index.html` - main/index page.
- `miniproject.html`, `miniproject.js`, `miniproject.css` - main mini-project files.
- `activity.html`, `activity.js`, `activity2.html`, `activity2.js` - activity exercises.
- `api.html`, `api2.js` - API exercise files.
- `function.html` - function exercise page.
- `object.html` - object exercise page.
- `guess.html`, `guessGame.js` - guessing game.
- `call.js`, `this.js` - JavaScript `call` and `this` practice.
- `todo.js` - to-do list functionality.
- `style.css` - shared styling for an exercise page.
